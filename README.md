#  My Journey to Data Engineering & AI

This repository is built to develop my software engineering skills while constructing a solid foundation for my ultimate goal: **Artificial Intelligence and Data Engineering**.

---

##  Project Scope & Architecture

To truly master AI, I believe in understanding the core logic behind the systems. That is why this journey starts from the absolute fundamentals:

* **Basic Sciences & Formulas:** Implementing core Physics, Chemistry, and High School Mathematics to master logic, clean code, and variables.
* **Linear Algebra From Scratch:** Building matrix operations, vector manipulations, and data transformations without relying on external libraries.
* **Data & AI Engineering:** Moving towards data pipelines, algorithms, and training machine learning models from the ground up.
